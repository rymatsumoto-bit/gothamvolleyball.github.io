# Gotham Volleyball: new gym breakeven calculator

A single-page tool to estimate the maximum annual venue budget Gotham can afford for a new gym, based on a weekly schedule, program revenues and costs, and fixed costs.

Open the live page from the link in this repository's About section. Your inputs autosave in your own browser only and are not shared with anyone.

All numbers in the defaults are illustrative placeholders. Replace them with your own.

## Local development

Requires [Node.js](https://nodejs.org/).

```
npm install
npm run dev
```

This serves the page at http://localhost:8080 and reloads the browser whenever you save `index.html`. The `package.json` is only for local tooling; GitHub Pages serves `index.html` directly.
